# Scam-shield-AI
AI-powered suspicious message analysis web app

ScamShield AI is an AI-powered web application that analyzes
suspicious messages and explains possible scam indicators.

## Features
- AI-powered message analysis
- Suspicious phrase explanations
- Risk assessment
- Recommended safety actions

## Technology Stack
- Python
- Streamlit
- Google Gemini API

## Run Locally
1. Install Python.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Create a `.env` file containing your Gemini API key.
4. Run:
   `python -m streamlit run app.py`

## Security
Never upload API keys, `.env` files, or passwords to GitHub.

## Disclaimer
AI results are not definitive proof of fraud.
